# Krea Prompts — Legacy Brand Assets

Copy-paste these into Krea (https://www.krea.ai). For logos, use **Krea Image** with the **Flux** or **Ideogram** model (Ideogram is best for in-image text). For mockups, use **Krea Image** with **Flux 1.1 Pro** or **Realtime**. Aspect ratios noted per prompt.

> Tip for transparent PNG logos: generate on a flat black or white background, then use Krea's **Erase / Remove Background** tool, or run the output through `remove.bg` afterward.

## Workflow Recommendation

1. Generate the **wordmark** and **symbol** first (prompts 1 & 2) — pick your favorite seed.
2. Use Krea's **Remove Background** to export transparent PNGs.
3. Generate the **mug** and **t-shirt** mockups (prompts 4–7). If Krea struggles to render the logo text accurately on fabric, generate a plain black t-shirt mockup first, then use Krea's **Inpaint / Edit** feature to add the logo cleanly.
4. Save outputs into the file structure described in `brand-identity.md` section 8.
