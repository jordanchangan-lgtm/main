# Latent Merch

Custom storefront for the Latent Merch apparel brand.
Next.js (App Router) + Supabase + Stripe + framer-motion.

## Setup
```bash
npm install
cp .env.example .env.local   # fill in keys
# apply supabase/schema.sql to your Supabase project
npm run dev
```

Read CLAUDE.md (architecture + security) and MIGRATION.md (porting the HTML prototype) before building.
